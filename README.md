# Δτ — Tau

A minimalist, dark-mode interval timer for Android, built for the Samsung Galaxy Z Flip 7.

`Δt` is the physics notation for a *time interval* — which is exactly what this measures.

## Features

- **Work / Rest / Rounds** — the classic interval timer, set with 5-second steppers.
- **Sequences & presets** — build custom interval sequences on the fly, save and name them; built-in Ladder, Pyramid, Tabata, and EMOM presets.
- **Drag to rearrange** — groups and the intervals inside them are dragged into place by their grip, and everything else slides out of the way. Each group repeats ×N, and the whole sequence can repeat ×N over the top of that. The editor won't put two rests back to back unless you ask it to (Settings).
- **Audio cues** — a distinct warning tone at 5s, ticks at 3/2/1, and a "go" tone at every transition. Plays as media so it follows your active route (headphones, Bluetooth) instead of the phone's speaker, and ducks your music only while a cue sounds.
- **Multilingual countdown** — the numbers and Work/Rest labels render in 9 languages using native glyphs (中文, 日本語, 한국어, हिन्दी, العربية, …), plus Cistercian, a 13th-century monastic cipher that packs the whole count into one drawn glyph. Languages that share Western numerals (e.g. Russian) can spell the count out instead, so it still reads as foreign at a glance.
- **Drift-free timing** — the clock lives in a foreground service anchored to `elapsedRealtime()`, so it stays accurate across backgrounding, and keeps beeping with the screen off. Toggle background-running off if you'd rather it stop when you close the app.
- **Aesthetic** — AMOLED black with a subtle, blurred aurora; liquid-glass controls; a glowing progress stroke tracing the screen edge; phase-colored glow (green work, blue rest, violet get-ready).
- **Fully local** — no accounts, no analytics, no tracking. Presets are stored as JSON on the
  device. The one exception, added in v1.1.0: the store is asked whether you own the one-time
  unlock. Nothing else leaves the phone.

## Build

Requires the Android SDK (API 36 / Android 16) and JDK 17+. Builds against API 36; runs on Android
8.0 (API 26) and up, with the AGSL aura and the blur effects degrading to gradients below API 33/31.

```bash
./gradlew assembleDebug
# output: app/build/outputs/apk/debug/app-debug.apk
```

Then sideload the APK onto your device. To run it on the Z Flip 7's cover display, use Good Lock → MultiStar.

For a release build, put an upload keystore in `keystore.properties` at the repo root (see
`keystore.properties.template`) and run `./gradlew :app:bundleRelease`. Without that file the release
variant still builds, signed with the debug key — installable locally, not uploadable.

The cue tones are generated by [`tools/gen_tones.py`](tools/gen_tones.py) into `app/src/main/res/raw/`.

## Notes

This is a personal side project, built to sideload. The release variant is set up for a Play Store
AAB (R8 + upload signing) but nothing has been published. The `research/` folder contains the design
and technical research the build was based on.
